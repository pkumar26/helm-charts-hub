To verify the Gateway and its auto-created service:

  kubectl get gateway {{ .Values.gateway.name }} -n {{ .Values.gateway.namespace }}
  kubectl get svc -n {{ .Values.gateway.namespace }} -l gateway.networking.k8s.io/gateway-name={{ .Values.gateway.name }}

To get the external IP (LoadBalancer):

  kubectl get svc -n {{ .Values.gateway.namespace }} \
    -l gateway.networking.k8s.io/gateway-name={{ .Values.gateway.name }} \
    -o jsonpath='{.items[0].status.loadBalancer.ingress[0].ip}'
