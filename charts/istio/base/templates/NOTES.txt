Thank you for installing {{ .Chart.Name }}.

Your Istio base (CRDs) release is named {{ .Release.Name }}.

To verify the installation, run:

  kubectl get crds | grep istio.io

You should see the following Istio CRDs installed:
  - authorizationpolicies.security.istio.io
  - destinationrules.networking.istio.io  
  - envoyfilters.networking.istio.io
  - gateways.networking.istio.io
  - peerauthentications.security.istio.io
  - proxyconfigs.networking.istio.io
  - requestauthentications.security.istio.io
  - serviceentries.networking.istio.io
  - sidecars.networking.istio.io
  - telemetries.telemetry.istio.io
  - virtualservices.networking.istio.io
  - wasmplugins.extensions.istio.io
  - workloadentries.networking.istio.io
  - workloadgroups.networking.istio.io

IMPORTANT: The control plane (istiod) and gateway must be installed next:

  # Install control plane
  helm install istiod charts/istio/istiod -n {{ include "istio-base.namespace" . }}

  # Install ingress gateway
  helm install istio-ingressgateway charts/istio/gateway -n {{ include "istio-base.namespace" . }}
